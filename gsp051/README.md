# GSP051 — Continuous Delivery with Jenkins in Kubernetes Engine

Reusable helper scripts for the Google Cloud Skills Boost GSP051 lab.

Run from Cloud Shell after starting your own lab:

```bash
curl -fsSL https://raw.githubusercontent.com/BuildWithRohan/DevOps/main/gsp051/part1.sh | bash
curl -fsSL https://raw.githubusercontent.com/BuildWithRohan/DevOps/main/gsp051/part2.sh | bash
curl -fsSL https://raw.githubusercontent.com/BuildWithRohan/DevOps/main/gsp051/part3.sh | bash
curl -fsSL https://raw.githubusercontent.com/BuildWithRohan/DevOps/main/gsp051/part4.sh | bash
```

Scripts use the active gcloud project and standard GSP051 resource names. Do not put credentials or tokens in this repository.
